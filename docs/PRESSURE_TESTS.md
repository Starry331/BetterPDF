# 压力测试与离线安装包核验 — 2026-11-17

本轮使用 macOS arm64 本机测试，重点检查大文件处理、取消、异常恢复和安装包完整性。不是所有机器/所有文件绝不崩溃的保证，也不替代 M1/8 GB、干净 macOS 14 与 GUI 长时间运行验收。

## 发现与修复

旧栅格化实现将所有页的位图保留在一个 MuPDF 工作进程中。对 1,000 页文件开始处理后，700 ms 取消测试已观察到约 863 MB 的工作进程树采样峰值，有随页数增长的风险。

现在栅格化、灰度和黑白转换逐页写出临时 PDF；每页工作进程退出后释放位图。qpdf 从磁盘合并编码流，并关闭不使用的输入文件，避免大量页同时占用文件句柄。OCR 的最后合并也使用这一流程。所有选中页面提前检查像素上限；取消或失败不提交部分文件，保留原件。页顺序与重复选页有实际渲染回归检查。

## 压力结果

输入为 1,000 页、201,734,734 字节 PDF，包含 64 张独立噪声图片，避免仅使用同一图片造成过于简单的内存测试。

| 检查 | 结果 |
|---|---|
| 整本 1,000 页栅格化，72 DPI | 43.245 秒；输出重新打开确认为 1,000 页 |
| 栅格化期间工作进程树采样内存峰值 | 43,581,440 字节（43.58 MB） |
| 栅格化期间并行读取最后一页 | 114 次均成功；每次 36–117 ms |
| 栅格化取消（700 ms 发出） | 0.760 秒返回；采样峰值 47.71 MB；无部分输出 |
| OCR 取消（700 ms 发出） | 0.753 秒返回；无部分输出 |
| 1,000 页旋转、无损压缩、提取及重复渲染 | 成功；30 次连续页面渲染无异常退出 |
| 原文件 | SHA-256 未改变 |
| 真实磁盘满 | 私有 32 MB 测试卷触发 ENOSPC；不发布部分文件；之后读取正常 |
| 工作进程崩溃、取消与文件访问隔离 | Rust 回归检查通过 |

共 43 条压力检查通过。RSS 每约 50 ms 采样，包含测试请求进程及其后代，不是 GUI 总内存，也不能捕获所有瞬时峰值。连续渲染测试中每次工作进程退出，不代表同一 GUI 会话的泄漏测试。重任务期间的读取为独立请求，不是界面 FPS 测量。

## DMG 完整性

全部已实现功能使用的 MuPDF、qpdf、Ghostscript、LibreOffice、Tesseract、简繁英及方向 OCR 模型、字体随应用内置。运行时不下载组件；构建时准备依赖与用户安装后的运行过程不同。

- 3,886 个运行资源文件按构建清单逐个校验大小和 SHA-256。
- 内置 128 个 Office 字体文件，另包含 MuPDF 自带字体。
- 检查必需组件、模型、颜色配置和符号链接，拒绝指向应用外部的资源链接。
- 从只读挂载 DMG 的资源路径执行 PDF 70/70 与 Office 18/18 全量集成测试并通过；测试环境 PATH 仅含系统目录，工作进程禁止网络访问。
- 完整应用占用 582,818,791 字节（582.82 MB），仍在原 700 MB 目标内；用户允许为完整内置小幅超出该目标。
- 下载包仍为开发版本，未做 Developer ID 签名/公证；首版未完成项目参见 STATUS.md。打包完整不等于尚未实现的功能已经完成。

## 重复执行

```sh
cargo build --manifest-path src-tauri/Cargo.toml --bin bpdf-cli
python3 scripts/stress-check.py
python3 scripts/large-stress-fixture.py
BPDF_STRESS_SOURCE="$PWD/work/stress/1000-pages-200MB.pdf" python3 scripts/pressure-check.py
python3 scripts/failure-check.py
python3 scripts/package-local-dmg.py
python3 scripts/test-packaged-dmg.py
```

压力脚本有 2 GiB 工作进程树与单任务时间保护，触发保护视为测试失败。磁盘满测试仅填满独立的小型临时镜像，不填满系统磁盘。
