## 正式发布尚未满足的条件

1. macOS 14 arm64 依赖重建及干净机器验证；Windows x64 依赖组装、独立安装程序及干净 Windows 11 验证。当前没有 Windows 成品安装包。
2. macOS 签名公证及 Windows 签名。当前没有发行证书配置或发行证据。
3. PDF/A-2b 已生成，尚未由 veraPDF 独立验收。
4. CAJ 只有标准嵌入 PDF/页面树修复路径和部分 HN JPEG 页面支持；复杂 HN/JBIG、加密变体不支持。现有 CAJ 测试是合成样本，缺少有代表性的真实授权样本库。
5. OCR 三种语言模型已内置；完整中文/繁体/旋转方向/混合页质量集未完成，自动方向纠正尚未实现。
6. 反向 Office 输出真实可编辑对象，但段落、表格及阅读顺序使用基础启发式，双栏、合并单元格、复杂公式等需扩展。尚未在 Microsoft Office 独立检查。
7. 正文编辑以所选文字行/区域重新写入，不能保持任意原字体及复杂文本块结构。字体缺失预览、完整编辑预览仍需完善。旋转图片移动目前按轴对齐矩形重建；重叠图片会拒绝修改。
8. 去水印当前为精确文字匹配；独立图片水印尚无识别/批量选择流程。
9. macOS 工作进程已禁止联网，但尚未落实最小文件访问范围；Windows 工作进程尚未配置等价系统沙箱。HTML 本地相对资源解析还需专门测试。
10. 基准硬件的冷启动、100 页首屏、1000 页内存、60fps、并发阅读、取消、磁盘满与崩溃恢复尚未全量验收。
11. 当前内置许可证材料不是完整可分发源代码包；固定依赖版本、来源和校验和、可复现构建及再分发材料尚待补齐。
12. 关闭窗口有未保存/运行任务确认；系统 Quit 及崩溃后的恢复流程仍需扩展验证。

正式打包入口会检查 `release-evidence.json` 中逐项验收报告；缺少证据时失败。这个门禁只检查证据存在性，不替代人工核验报告。

## 2026-11-05：局域网协作与大文件保护

首页页脚 GitHub 按钮默认指向 https://github.com/Starry331/BetterPDF 。应用打包显式包含 macOS icns 与 Windows ico 图标。

已实现邀请式局域网协作：指定私有 IPv4 监听地址，TLS 加密，邀请中固定服务端证书与随机访问凭证；共享当前文档的独立副本，不修改输入文件。主持端统一串行提交编辑，版本冲突明确拒绝，操作 ID 防止重试造成重复修改；退出共享使邀请失效。客户端以 2 秒间隔检查版本，仅变化时分块接收完整 PDF，未变更时只传元数据。最多 8 个并发连接、单文件 2 GB、协议消息 256 KB。邀请码只保留在运行会话中，不记日志、不写最近文件列表。

真实本机 TLS 双客户端测试通过：首次读取、未变化检查、修改同步、同页过期版本冲突、不同页并行提交、重复提交、错误凭证、错误证书及结束共享。**尚未完成 macOS 与 Windows 两台实体设备联机验收，不宣称跨平台发布已完成。** 当前采用页面级乐观并发控制：不同页面允许基于旧版本提交，同一页面拒绝过期修改；表单修改保守地检查全局版本。不是字符级实时合并。编辑期间继续同步，文字草稿可以保留并在重新选择后恢复。远程图片移动/删除可用，图片替换由主持端进行。协作期间禁用历史撤销，退出后继续编辑本地副本。主持端离线后，客户端保留已收到的本地副本，不自动创建分叉合并。

阅读内容现在按视口虚拟挂载，渲染并发上限 2；文字提取不随缩放重复进行；页面位图上限 4,000 万像素，超限返回错误；文档信息限制 20,000 页；组件标准输出上限 32 MB、错误输出上限 8 MB；历史版本最多 32 个，超出 512 MB 时清理较旧中间版本（保留原始版本与当前版本，因此大文件保留的两份本身仍可能超过 512 MB）。所有修改仍另存，转换异常不覆盖原件。这些措施不能保证任意损坏/恶意文件或系统磁盘耗尽时永不崩溃。

新增合成压力样本：1,000 页、28.72 MB，分别打开并渲染第 1/500/1,000 页，验证超大页面被拒绝后正常文档仍可读取。原始结果见 `work/stress/results.json`。测试测量的是本机原生处理进程，不是完整 GUI 总内存，也不是指定 M1/i5 基准设备验收。

新增 macOS 14 / Windows 2022 源码检查工作流（尚未在远程运行）；不将源码编译检查当成 Windows 安装包交付。现有 macOS 开发运行库仍需要 macOS 27.2。正式签名、Windows 运行组件、真实 CAJ/HN 样本、PDF/A 独立验证和最低系统兼容构建仍需继续完成。

桌面界面验证：实际打开上述 1,000 页文件，通过页码输入跳转至第 1,000 页，确认页面内容渲染；使用 `127.0.0.1` 在 GUI 创建共享副本并结束共享，界面状态更新正常。这只验证本机流程，未使用其他人的网络设备。

## 本轮效率与协作优化

阅读渲染队列最多同时执行 2 项，文字提取最多 1 项；可见正文优先于缩略图，离开视口的排队请求取消。文字缓存限制 4 MiB / 24 页。工具参数或文件变化后清除旧预览，过时的异步结果不会重新覆盖预览。协作同步最多 2 个并行请求，各会话独立失败重试，失败后逐步延长至 30 秒，并支持手动同步、最后同步时间和复制邀请。当前仍按变更后的完整 PDF 同步，大文件频繁共同编辑的带宽和延迟尚需实机测试。

macOS 导航栏为原生红绿灯预留 88 pt 宽与 52 pt 顶部空间；原生菜单支持中英文切换，包含设置、打开、另存副本、打印、关闭文档、撤销重做、文本复制粘贴、查找、缩放、适合宽度、页间导航、侧栏切换、工具、任务、协作及 GitHub。退出菜单走现有未保存更改确认流程。

窗口按钮修复：移除 trafficLightPosition 自定义坐标，保留 Overlay 标题栏并明确开启 decorations、关闭、最小化和最大化功能。红绿灯由 macOS 默认布局管理，侧栏仍保留顶部避让空间。

窗口关闭修复：为 onCloseRequested 完成关闭流程补充 core:window:allow-destroy 权限。修复版重新启动后，系统无障碍树确认关闭、最小化和全屏按钮均存在；实际点击原生关闭按钮后进程正常退出。
